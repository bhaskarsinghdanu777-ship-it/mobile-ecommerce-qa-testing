## Mobile E-Commerce Application — QA Testing Project

- **Designed and executed** 37 manual test cases for an Android e-commerce application (Sauce Labs My Demo App) on a Pixel 8 emulator, covering functional, negative, UI, navigation, cart, checkout, and sorting scenarios across multiple application modules.
- Executed **complete checkout and payment flow** (9 consecutive tests) with **100% pass rate**, verifying the application's critical business functionality.
- Created comprehensive QA documentation including test plan, test cases, execution reports with evidence tracking, regression suite, and defect analysis following industry-standard practices.
- **Executed and verified** a 12-case regression suite testing critical user flows — all 12 tests PASSED, confirming core functionality stability.
- Automated test execution using Python with ADB and UIAutomator, capturing 56 PNG screenshots as evidence of test execution against the running application.
- **Executed 10 REST API tests** using curl and Postman, validating GET, POST, PUT, PATCH, and DELETE methods with full response validation (100% pass rate).
- Organized complete QA artifacts, test evidence (56 screenshots), test results (JSON format), and professional documentation in a GitHub-ready repository structure.
- **Verified no genuine application defects** — investigated 5 failed and 18 blocked test results; determined these were test automation limitations, not app bugs.
